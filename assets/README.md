# Assets

This folder contains promotional and store listing assets for the Chrome Web Store.

## Required for Chrome Web Store submission

| Asset | Size | Status |
|-------|------|--------|
| Icon 16×16 | 16×16 PNG | ✅ `/extension/icons/icon16.png` |
| Icon 48×48 | 48×48 PNG | ✅ `/extension/icons/icon48.png` |
| Icon 128×128 | 128×128 PNG | ✅ `/extension/icons/icon128.png` |
| Promotional tile | 440×280 PNG | ⬜ Add here |
| Screenshot 1 | 1280×800 or 640×400 PNG | ⬜ Add here |
| Screenshot 2 | 1280×800 or 640×400 PNG | ⬜ Add here |
| Screenshot 3 | 1280×800 or 640×400 PNG | ⬜ Add here |

## Naming Convention

```
screenshot-v{version}-{feature}.png
promo-tile-v{version}.png
```

Examples:
```
screenshot-v3.0.0-hover-mode.png
screenshot-v3.0.0-colour-panel.png
screenshot-v3.0.0-locked-tooltip.png
promo-tile-v3.0.0.png
```
